My Interest - Robotics Build Progress Tracker
For this class, I want to create a Robotics Build Progress Tracker using C++. The program would help me keep track of the different parts of our robot, what has been completed, and what still needs to be finished.

My goal is to eventually have the program calculate the overall percentage of how close our robot is to being competition-ready.

As I learn more C++, I would like to add features such as tracking team member responsibilities, deadlines, problems that need to be fixed, and robot testing results.
